
### 10. RGB Color Picker Using Trackbars

**Description:**
This project demonstrates how to create a real-time color picker using OpenCV trackbars. Users can adjust Red, Green, and Blue values using sliders and enable or disable the selected color using a switch.

**Concepts Learned:**

- Creating and managing OpenCV trackbars.
- Reading trackbar positions using `cv2.getTrackbarPos()`.
- Implementing ON/OFF functionality using a switch.
- Understanding RGB color values and OpenCV's BGR color format.
- Updating image pixel values dynamically.
- Using NumPy slicing to change the entire image color.

**Controls:**

- **Switch OFF (0):** Displays a white background.
- **Switch ON (1):** Displays the selected color.
- **R, G, B sliders:** Adjust the color intensity.
- **ESC:** Exit the application.

**Status:** Completed
