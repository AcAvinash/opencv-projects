
# 05 - OpenCV Drawing Functions

This project demonstrates basic drawing functions in OpenCV using Python and NumPy.

## Functions Covered

- `cv2.line()` – Draws a straight line.
- `cv2.arrowedLine()` – Draws an arrowed line.
- `cv2.rectangle()` – Draws outlined and filled rectangles.
- `cv2.circle()` – Draws outlined and filled circles.
- `cv2.putText()` – Adds text to an image.
- `cv2.ellipse()` – Draws an ellipse.
- `np.zeros()` – Creates a black image.
- `np.ones()` – Creates a white image when multiplied by 255.

## Technologies Used

- Python
- OpenCV
- NumPy

## How to Run

Install the required libraries:

```bash
pip install opencv-python numpy
```

Run the Python file:

```bash
python main.py
```

Press any key to close the image window.

## Learning Outcome

Learned how to create blank images, draw shapes, add text, and control drawing colors and thickness using OpenCV.
